Coverage and interpretation

These results are independent of the daily workload score. TypeRB Go compiles the same TypeRB application; Pure Go uses an idiomatic implementation with matching observable output. Differences within 5% are labelled “About the same” as a screening aid, not a statistical guarantee. Missing values never count as wins.

Input variants include invalid records, missing keys, Unicode text, sorted and duplicate-heavy arrays, and retained objects. Process startup can dominate small inputs. Throughput includes setup and output.

Remaining gaps

Inputs are in memory. File and network I/O, service queueing and latency, parallel scaling and production traces still need dedicated coverage. Worker batch intervals are observer-side diagnostics, not request latency. Sparse samples cannot establish p95 or p99; this page shows process medians.
