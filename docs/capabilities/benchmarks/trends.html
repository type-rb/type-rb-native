Changes you can act on

Current, previous and frozen Native compilers run the same workload on the same host. TypeRB Go compiles the identical source. Negative changes mean less time, memory or space. Changes below 5% are visually neutral; this is a screening aid, not a statistical acceptance threshold.

Runtime ranges show the retained minimum and maximum. Trends retain up to 60 snapshots and show only the current measurement series. Input or measurement-policy changes start a new series.

Freshness without blocking development

Performance changes are measured once a day, around 06:23 JST, or on demand. GitHub scheduling may be delayed. An unchanged day needs no benchmark run. The daily update is independent of PR acceptance.

Numerical regressions are published. A failed measurement is shown explicitly; infrastructure failures preserve the last measured snapshot.

Read the measurements in scope

These are small workloads, not a general language score. Builds use clean output directories with a warm Go cache. Runtime includes fresh-process startup, with warm filesystem caches. Startup measurements include the launch harness; very short CPU and RSS observations may be below measurement resolution.
